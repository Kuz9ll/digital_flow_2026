## 3.3. Команды импорта в Innovus

Переменные, объявленные в Makefile через `export`, доступны внутри Tcl как элементы `::env`.

Импорт выполняется процедурой `user_init_design`:

```tcl
    # Настройка технологического узла
    if {[info exists ::env(TECH_SIZE)] && $::env(TECH_SIZE) ne ""} {
        set_db design_process_node $::env(TECH_SIZE)
    }

    # Исходные данные и сети питания
    set_db init_netlist_files $::env(ENV_NETLIST)
    set_db init_lef_files     $::env(ENV_LEF_FILES)
    set_db init_power_nets    $::env(ENV_POWER_NETS)
    set_db init_ground_nets   $::env(ENV_GROUND_NETS)
    set_db init_mmmc_files    $::env(ENV_MMMC)

    # Чтение конфигурации анализа и физических библиотек
    read_mmmc $::env(ENV_MMMC)
    read_physical -lef $::env(ENV_LEF_FILES)

    # Чтение netlist и инициализация проекта
    read_netlist $::env(ENV_NETLIST) -top $::env(ENV_DESIGN)
    init_design
```

Команды выполняют следующие действия:

| Команда | Назначение |
| --- | --- |
| `set_db design_process_node` | Задаёт технологический узел для настроек инструмента; не заменяет загрузку PDK |
| `set_db init_*` | Задаёт параметры инициализации |
| `read_mmmc` | Читает конфигурацию режимов и условий анализа |
| `read_physical -lef` | Загружает физические описания из LEF |
| `read_netlist ... -top ...` | Загружает netlist и выбирает верхний модуль |
| `init_design` | Выполняет инициализацию проекта на основе загруженных данных |

# 4. Геометрия floorplan

При создании floorplan задаются размеры блока, область размещения стандартных ячеек и периферийные отступы. Основные понятия этого этапа — **die**, **core**, **rows** и **site**.

## 4.1. Die, core, rows и site

**Die** — внешняя граница проектируемой области. При проектировании целой микросхемы она соответствует границе кристалла, а при реализации отдельного блока — границе этого блока.

**Core** — внутренняя область, предназначенная для размещения стандартных ячеек. Между границами die и core задаются отступы. В этой лабораторной работе периферийная область используется для кольца питания и сигнальных пинов; устанавливать отдельные IO pad cells не требуется.

**Rows** — ряды внутри core, в которых размещаются стандартные ячейки. Ряды задают допустимые положения и ориентации ячеек. Их участки можно удалять, исключая соответствующие области из размещения.

**Site** — базовая единица сетки размещения, описанная в LEF. Она задаёт ширину и высоту места размещения. Ширина стандартной ячейки обычно кратна ширине site; высота обычной однорядной ячейки соответствует высоте ряда.

Таким образом, die определяет внешние размеры блока, core — область размещения логики, rows — организацию рядов, а site — шаг сетки размещения.

## 4.2. Создание floorplan через GUI

В окне настройки floorplan геометрию можно задать двумя способами:

- **через целевую плотность размещения** — инструмент рассчитывает размеры области по площади стандартных ячеек;
- **через явные размеры** — пользователь вводит заранее рассчитанные ширину и высоту.

Основные параметры настройки:

| Параметр | Назначение |
| --- | --- |
| Cell Utilization | Целевая доля площади core, занимаемая стандартными ячейками |
| Aspect Ratio | Соотношение сторон области; порядок сторон следует проверить по обозначениям в окне |
| Core Margins / Offsets | Отступы между границами core и die с каждой стороны |
| Width / Height | Ширина и высота области при явном задании размеров |

### Задание через Cell Utilization

При использовании **Cell Utilization** инструмент рассчитывает размеры core по суммарной площади стандартных ячеек и заданной плотности. Например, значение 50% означает, что суммарная площадь ячеек составляет половину площади core.

Для определения формы области задаётся соотношение сторон, а для формирования периферийной области — отступы между core и die.

Отступы формируют периферийную область между core и die. Её размеры выбирают с учётом расположения кольца питания, сигнальных пинов и технологических ограничений.

## 4.3. Расчёт площади и размеров floorplan

Плотность заполнения показывает, какую долю выбранной области занимает суммарная площадь стандартных ячеек. При расчёте относительно площади core:

$$
U_{core}=\frac{A_{cells}}{A_{core}},
$$

где:

- **U_core** — плотность заполнения core, безразмерная величина; например, 50% соответствует 0.5;
- **A_cells** — суммарная площадь стандартных ячеек, мкм²;
- **A_core** — площадь core, мкм².

### Определение площади ячеек по отчёту синтеза

Для расчёта используйте **отчёт о площади (`report_area`) итоговой схемы после синтеза и оптимизации**, полученный в лабораторной работе №2.

1. Откройте отчёт о площади.
2. Найдите строку своего блока — `blockA` или `blockB`.
3. Определите суммарную площадь ячеек блока. В зависимости от формата отчёта соответствующее поле может называться **Cell Area**, **Instance Area** или **Total Cell Area**.
4. Проверьте единицы измерения. Для получения размеров в мкм площадь должна быть выражена в мкм².

Если отчёт содержит иерархию, используйте итоговую площадь блока **с учётом всех вложенных экземпляров**. Не складывайте её повторно с площадями дочерних модулей: это приведёт к двойному учёту.

Условный пример отчёта:

```text
Instance    Cell Count    Cell Area
----------------------------------
blockA             420     10000.00
```

Если площадь указана в мкм², для этого примера **A_cells = 10 000 мкм²**.

**Cell Count** — количество ячеек, а **Cell Area** — их суммарная площадь. Для расчёта размеров floorplan используется площадь, а не количество.

> Используйте данные для итогового netlist, который импортируется в Innovus. Площадь межсоединений, если она приведена отдельно, в A_cells не включается.

### Расчёт площади core

Для заданной целевой плотности:

$$
A_{core}=\frac{A_{cells}}{U_{core}},
$$

где:

- **A_core** — требуемая площадь core, мкм²;
- **A_cells** — суммарная площадь ячеек из отчёта синтеза, мкм²;
- **U_core** — выбранная целевая плотность в долях единицы.

При плотности 50%:

$$
A_{core}=2A_{cells}.
$$

Здесь **A_core** — площадь core, а **A_cells** — суммарная площадь ячеек; обе величины выражаются в мкм².

При неизменном составе ячеек увеличение площади core уменьшает плотность, а уменьшение площади — повышает её. Эта зависимость показана на рисунке 5.

### Расчёт ширины и высоты core

Одной площади недостаточно для определения формы блока: необходимо выбрать соотношение сторон:

$$
r=\frac{W_{core}}{H_{core}},
$$

где:

- **r** — отношение ширины core к его высоте, безразмерная величина;
- **W_core** — ширина core, мкм;
- **H_core** — высота core, мкм.

По площади и соотношению сторон размеры определяются следующим образом:

$$
W_{core}=\sqrt{rA_{core}},
\qquad
H_{core}=\sqrt{\frac{A_{core}}{r}},
$$

где:

- **W_core**, **H_core** — рассчитываемые ширина и высота core, мкм;
- **A_core** — площадь core, мкм²;
- **r** — выбранное отношение ширины к высоте.

Для квадратного core **r = 1**, поэтому:

$$
W_{core}=H_{core}=\sqrt{A_{core}},
$$

где **W_core** и **H_core** — стороны квадратного core в мкм, а **A_core** — его площадь в мкм².

### Расчёт размеров die

Размеры die определяются добавлением периферийных отступов к размерам core:

$$
W_{die}=W_{core}+m_L+m_R,
$$

$$
H_{die}=H_{core}+m_B+m_T,
$$

где:

- **W_die**, **H_die** — ширина и высота die, мкм;
- **W_core**, **H_core** — ширина и высота core, мкм;
- **m_L**, **m_R** — отступы между core и die слева и справа, мкм;
- **m_B**, **m_T** — отступы между core и die снизу и сверху, мкм.

Отступы выбираются с учётом места для кольца питания, сигнальных пинов и необходимых технологических расстояний.

### Пример расчёта

Исходные данные:

| Параметр | Значение |
| --- | --- |
| Суммарная площадь ячеек A_cells | 10 000 мкм² |
| Целевая плотность U_core | 0.5, или 50% |
| Соотношение сторон r | 1 — квадратный core |
| Отступы m_L, m_R, m_B, m_T | По 10 мкм |

Площадь core:

$$
A_{core}=\frac{10\,000}{0.5}=20\,000\text{ мкм}^2,
$$

где **A_core** — требуемая площадь core.

Ширина и высота core:

$$
W_{core}=H_{core}=\sqrt{20\,000}\approx141.42\text{ мкм},
$$

где **W_core** и **H_core** — размеры квадратного core.

При отступах по 10 мкм с каждой стороны размеры die:

$$
W_{die}=H_{die}\approx141.42+10+10=161.42\text{ мкм},
$$

где **W_die** и **H_die** — ширина и высота die.

Если установлено ограничение **die не менее 200 × 200 мкм**, при сохранении отступов по 10 мкм размеры core составят:

$$
W_{core}=H_{core}=200-10-10=180\text{ мкм},
$$

где **W_core** и **H_core** — размеры core после увеличения die.

Фактическая плотность:

$$
U_{core}=\frac{10\,000}{180\cdot180}\approx0.309=30.9\%,
$$

где **U_core** — отношение площади ячеек к новой площади core.

Таким образом, ограничение минимального размера die может привести к плотности ниже целевой. Отступы в этом примере условные; их допустимость проверяется отдельно.

### Фактическая геометрия и плотность

Рассчитанные размеры необходимо согласовать с сеткой размещения: шириной site и высотой rows. После округления следует повторно вычислить плотность по фактической площади core.

Удаление участков rows и создание hard placement blockages уменьшают доступную площадь размещения, но не меняют геометрическую площадь core. Поэтому плотность относительно core и плотность относительно доступной области могут различаться.

> При сравнении ручного расчёта с отчётом инструмента проверяйте, какая площадь используется в знаменателе: площадь core, площадь оставшихся rows или доступная площадь с учётом ограничений размещения.

### Что учитывают при выборе сети питания

- **Потребляемый ток** — ток, необходимый для работы ячеек блока. Чем больше ток через участок сети, тем больше падение напряжения на его сопротивлении и нагрузка на проводники и vias.

- **Допустимое падение напряжения** — насколько напряжение питания у ячеек может уменьшиться относительно напряжения источника. Например, при источнике 1.2 В и допустимых потерях 0.06 В напряжение между VDD и VSS у ячеек должно быть не менее 1.14 В.

- **Сопротивление проводников и vias** — сопротивление пути от источника питания до ячеек и обратно. Длинные и узкие проводники имеют большее сопротивление; переходы между слоями также вносят свой вклад.

- **Технологические ограничения** — правила изготовления и надёжности: допустимые ширины металла, расстояния между проводниками, геометрия vias и предельные токи. Например, слишком близкие шины могут нарушать правила расстояний, а недостаточное количество vias — не обеспечивать допустимую токовую нагрузку.

### Оценка потребляемого тока

Средний ток блока можно оценить по его мощности и напряжению питания:

$$
I_{avg}=\frac{P}{V_{DD}},
$$

где:

- **I_avg** — средний потребляемый ток блока, А;
- **P** — суммарная мощность блока, Вт;
- **V_DD** — напряжение питания блока относительно VSS, В.

Мощность возьмите из отчёта **report_power**, полученного в лабораторной работе №2 для итоговой схемы. Используйте суммарное значение **Total Power** своего блока и проверьте единицы измерения. Напряжение должно соответствовать условиям этого отчёта.

Например, при мощности 12 мВт и напряжении 1.2 В средний ток составляет **10 мА**. Такая оценка не определяет пиковый ток при одновременном переключении ячеек.

### Влияние геометрии проводников

При протекании тока через сопротивление проводника возникает падение напряжения:

$$
\Delta V=IR,
$$

где:

- **ΔV** — падение напряжения на участке, В;
- **I** — ток через участок, А;
- **R** — сопротивление участка, Ом.

Для прямого участка постоянной ширины:

$$
R=R_{\mathrm{sq}}\cdot\frac{L}{w},
$$

где:

- **R** — сопротивление участка проводника, Ом;
- **R_sq** — сопротивление квадрата выбранного слоя металла, Ом/□;
- **L** — длина участка, мкм;
- **w** — ширина участка, мкм.

Длина и ширина должны быть выражены в одинаковых единицах. Сопротивление квадрата берётся из технологических данных выбранного металла.

При неизменном токе более длинный проводник имеет большее сопротивление, а более широкий — меньшее. При этом увеличение ширины и количества stripes занимает ресурсы трассировки.

4. **Определите общую площадь металла сети питания** по выбранной геометрии.

### Оценка площади металла

Для прямоугольного участка проводника:

$$
A_i=L_iw_i,
$$

где:

- **A_i** — площадь участка металла, мкм²;
- **L_i** — длина участка, мкм;
- **w_i** — ширина участка, мкм.

Для предварительного подсчёта разделите проводники каждого слоя на неперекрывающиеся участки. Тогда общая площадь металла сети:

$$
A_{PG}=\sum_{i=1}^{N}A_i,
$$

где:

- **A_PG** — суммарная площадь металла сети питания по всем используемым слоям, мкм²;
- **A_i** — площадь отдельного неперекрывающегося участка, мкм²;
- **N** — количество учитываемых участков.

Пересечения и соединения на одном слое учитываются только один раз. Площади разных слоёв суммируются, даже если проводники совпадают в проекции. Площадь переходов vias учитывается отдельно.

Таким образом, A_PG — это сумма площадей металла по слоям, а не площадь, занятая сетью в проекции на die.

**Это предварительная оценка до размещения ячеек.** Она не учитывает фактические скопления элементов и локальное распределение потребления. Оценка среднего тока сама по себе не определяет необходимые ширины и шаг stripes: выбранная геометрия остаётся исходным предположением.

Подробная проверка сети по падению напряжения, распределению токов и ограничениям электромиграции рассматривается в лабораторной работе по IR Drop.

**Геометрическая корректность и связность ещё не подтверждают достаточность сети питания.** Подробный выбор ширин и шага по падению напряжения, распределению токов и ограничениям электромиграции рассматривается в лабораторной работе по IR Drop.

### Routing blockage и отличие от placement blockage

**Routing blockage** — область с ограничением трассировки на выбранном слое или наборе слоёв металла. При его создании необходимо задать границы и слои. Он не запрещает размещение стандартных ячеек и не удаляет rows или уже существующие проводники.

| --- | --- | --- |
| Hard placement blockage | Запрещает размещение стандартных ячеек внутри области | Нет |
| Routing blockage | Ограничивает прокладку проводников на указанных слоях | Нет |
| Cut row | Удаляет ряды или их участки в заданной области | Да |

# Лабораторное задание

# 10. Задание

Используйте итоговый netlist своего блока `blockA` или `blockB`, полученный в лабораторной работе №2 и успешно прошедший LEC. Каждый студент выполняет физическую реализацию своего блока. При индивидуальном выполнении используется выбранный функциональный блок.

Работа разделена на обязательную часть с максимальной оценкой 4 и дополнительную часть для оценки 5. В обоих случаях студент должен понимать выполненные действия и объяснять результат. Ограничения максимальной оценки по срокам действуют по общим правилам курса.

## 10.1. Задание на 4 балла

1. Импортируйте проект своего блока в Innovus и сохраните исходную базу после импорта.

2. Создайте floorplan через GUI: в окне настройки задайте **Cell Utilization = 50%**. Если поле использует долю вместо процентов, укажите **0.5**. Сформируйте core и периферийную IO-область. Ширина и высота die должны быть не менее 200 мкм. При необходимости увеличьте размеры с сохранением выбранных IO-отступов и укажите фактическую плотность ниже 50%. Покажите целевое значение, фактическую плотность, размеры и отступы.

3. Создайте rows для размещения стандартных ячеек.

4. Расположите все сигнальные пины по своему усмотрению на разрешённых границах блока.

5. Создайте кольцо питания VDD/VSS по периметру блока.

6. Создайте горизонтальные проводники питания вдоль rows и подключите их к соответствующим кольцам.

7. Добавьте **placement blockage между границей die и внутренней границей кольца питания**, как показано на рисунке.

8. Проверьте геометрию и соединения, проанализируйте сообщения инструмента и сохраните итоговую базу.

![Задание на 4 балла](doc/images/lab3_level4.png)

*Схема задания на 4 балла. Серый — rows; красный и синий — две сети питания; полупрозрачные горизонтальные линии — проводники питания; жёлтая штрихованная область — placement blockage. Положение сигнальных пинов произвольное. Рисунок условный: размеры, число рядов и проводников определяются параметрами своего блока и технологии.*

Для оценки 4 все операции можно выполнять удобным способом: через GUI, команды в консоли или скрипт. **Использование команд и предоставление отдельного Tcl-скрипта не обязательны.**

Rows на схеме показаны по всей площади die для наглядности. В базе Innovus создавайте их в предусмотренной окружением области core с допустимыми отступами. На 4 вырезать rows не требуется: placement blockage запрещает размещение в выделенной области, но не удаляет ряды.

Размеры core определяются инструментом по площади своего блока, значению Cell Utilization и выбранному соотношению сторон. Единый размер для разных блоков не задаётся. Ручной расчёт размеров для оценки 4 не требуется.

**Для сдачи предоставьте:**

- **сохранённый floorplan** — результат задания на 4;

- изображения готового floorplan с rows, сигнальными пинами, кольцом питания, горизонтальными проводниками питания и placement blockage;

- целевое значение Cell Utilization, фактическую плотность, размеры die/core и IO-отступы; каждая сторона die — не менее 200 мкм;

- log и результаты выполненных проверок.

**Tcl-скрипт для сдачи на 4 балла не требуется.**

## 10.2. Задание на 5 баллов

Сначала выполните **задание на 4 балла и сохраните полученный floorplan**. Затем на его основе выполните дополнительные условия.

1. **Самостоятельно рассчитайте размеры floorplan по результатам лабораторной работы №2**, используя раздел **4.3 «Площадь и плотность: пояснение и расчёт»**:

   - возьмите суммарную **площадь стандартных ячеек** своего блока из отчёта area и укажите единицы измерения;

   - для целевой плотности **50%** определите площадь core: площадь ячеек / 0.5;

   - выберите и укажите отношение ширины core к его высоте; рассчитайте ширину и высоту core;

   - сформируйте периферийную IO-область: выберите отступы между core и die для кольца и сигнальных пинов, затем рассчитайте размеры die;

   - обеспечьте ширину и высоту die не менее 200 мкм: каждую сторону die примите равной большему из рассчитанного значения и 200 мкм; затем определите фактические размеры core вычитанием IO-отступов и пересчитайте плотность;

   - если ограничение 200 мкм увеличило core, допускается плотность ниже 50%; покажите оба расчёта — для целевых 50% и для выбранной итоговой геометрии;

   - сравните расчёт с результатом задания на 4. Для задания на 5 задайте геометрию **явными рассчитанными размерами**, а не подбором через Cell Utilization. Покажите фактические размеры после округления по site и rows и полученную исходную плотность.

   Площадь ячеек из отчёта синтеза и плотность заполнения — разные величины. 50% относится к площади core до вырезания rows. Отступы добавляются при переходе от размеров core к размерам die.

2. **Расположите сигнальные пины заданным образом:** входы — слева, компактной группой по центру; `clk` — сверху; выходы — справа, равномерно распределив по высоте блока.

3. **Задайте параметры кольца питания относительно размера die** по таблице ниже. Каждая сеть VDD/VSS должна образовывать замкнутое кольцо с необходимыми vias.

4. **Добавьте в центре блока два толстых вертикальных проводника питания:** один для VDD, второй для VSS. Используйте два верхних разрешённых слоя металла. Каждый проводник соединяет верхнюю и нижнюю стороны соответствующего кольца. При переходах между слоями создайте необходимые vias.

5. **Удалите placement blockage по периметру**, созданный в задании на 4, и **вырежьте rows в этой области** — от границы die до внутренней границы кольца питания. Внутри кольца сохраните rows и горизонтальные проводники питания.

6. **Создайте два дополнительных прямоугольных blockage** по координатам A–D из таблицы ниже: hard placement blockage и routing blockage. Для routing blockage выберите разрешённый слой металла и укажите его при сдаче. Области не должны перекрывать кольцо и центральные проводники питания.

7. **Подготовьте два Tcl-скрипта:** первый создаёт floorplan задания на 4 из исходной базы после импорта netlist с целевым Cell Utilization = 50%, минимальным размером die 200 × 200 мкм и выделенной IO-областью; второй выполняет дополнительные изменения задания на 5 на сохранённом floorplan задания на 4, включая задание рассчитанных размеров и изменение параметров кольца при необходимости. Если размеры меняются, пересоздайте зависимые объекты по новой геометрии.

8. **Проверьте воспроизводимость:** выполните первый скрипт из исходного проекта, сохраните и заново загрузите результат задания на 4, затем выполните второй скрипт. Оба результата должны воспроизводиться без ручного редактирования.

9. **Рассчитайте плотность относительно оставшейся площади rows** и сравните её с исходной плотностью относительно core. Покажите использованные площади и объясните различие. Дополнительный placement blockage не удаляет rows: его площадь укажите отдельно.

10. **Сохраните результат задания на 5 под отдельным именем**, сохранив также floorplan задания на 4.

### Параметры кольца питания

Обозначения: **W** — ширина die, **H** — высота die, **L = min(W, H)** — меньшая сторона die. Все размеры для расчёта выражаются в мкм.

| Обозначение на рисунке | Параметр | Как определить значение |
| --- | --- | --- |
| w | Ширина каждой шины VDD/VSS | 2% от L, но не более 20 мкм |
| s | Расстояние между краями шин VDD и VSS | 1% от L, но не более 20 мкм |
| o | Отступ от границы die до внешнего края кольца | 2% от L, но не более 20 мкм |

Для каждого параметра сначала рассчитайте соответствующий процент от L. Если результат превышает 20 мкм, используйте 20 мкм.

Округлите значения по технологической сетке. Они должны удовлетворять минимальным правилам выбранных слоёв и оставаться не больше 20 мкм. Если выполнить оба условия невозможно, согласуйте параметры с преподавателем. Кольцо должно целиком помещаться внутри die и не перекрывать сигнальные пины.

**Пример:** die 200 × 300 мкм → L = 200 мкм → w = 4 мкм, s = 2 мкм, o = 4 мкм. Рисунок условный и не задаёт масштаб этих параметров.

### Координаты дополнительных blockages

**O = (x0, y0)** — нижний левый угол die. X отсчитывается от левой стороны, Y — от нижней. W — ширина die, H — высота.

| Объект | Точка | X | Y |
| --- | --- | --- | --- |
| Hard placement blockage | A — нижний левый угол | x0 + 0.20 × W | y0 + 0.57 × H |
| Hard placement blockage | B — верхний правый угол | x0 + 0.36 × W | y0 + 0.74 × H |
| Routing blockage | C — нижний левый угол | x0 + 0.65 × W | y0 + 0.27 × H |
| Routing blockage | D — верхний правый угол | x0 + 0.81 × W | y0 + 0.44 × H |

Например, X точки A находится на расстоянии 20% ширины die от его левой границы, а Y — на расстоянии 57% высоты от нижней границы. Координаты округлите по допустимой сетке инструмента.
